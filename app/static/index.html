Новое подключение

По умолчанию выключено. Генератор работает под этим же пользователем: создаёт таблицы LG_DATA, LG_LOG, LG_HOT (около 20 МБ) и по кругу запускает случайную нагрузку. Нужны права CREATE TABLE и квота. По умолчанию выключено. Генератор работает под этим же пользователем: создаёт схему pgash_load (около 60–80 МБ) и по кругу запускает случайную нагрузку. Нужно право CREATE в базе. Не включайте на рабочей базе. Нагрузка — свойство базы: если это база сервера, флажок включает и выключает её нагрузку (как кнопка в списке).

Пользователю мониторинга нужны права CREATE SESSION и SELECT_CATALOG_ROLE (или SELECT ANY DICTIONARY).
